# Product Requirements Document (PRD)

## Project Overview
A premium, full-service Digital Agency Website with a Custom Admin Dashboard. The core team consists of 4 roles:
1. Web Developer / UI/UX
2. Graphic Designer / Digital Marketing
3. Videographer / Photographer
4. Data Entry
The website must showcase digital services, case studies, and allow dynamic content management without breaking the layout.

## Core Features (Public Facing)
1. **Home Page:** Hero section, Bento Grid service highlights, and portfolio glimpses.
2. **About Us Page:** Agency mission, impact numbers, 2x2 grid for "Meet the Team", and workflow process.
3. **Services Page:** Detailed breakdown of offerings. Must be highly scalable for future additions (e.g., adding Interior Design later).
4. **Portfolio / Case Studies Page:** Masonry grid of past work with category filters.
5. **Contact Page:** Functional contact form and direct communication links.

## Core Features (Admin Dashboard)
1. **Authentication:** Secure login for the agency team (specifically for the Data Entry role).
2. **Content Management:** CRUD (Create, Read, Update, Delete) operations for Services.
3. **Portfolio Management:** CRUD operations for Case Studies.
4. **Messages:** View contact form submissions.
